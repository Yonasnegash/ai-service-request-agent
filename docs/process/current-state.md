
### Current state — before automation

1. Employee receives and reads the service request.
2. Employee identifies the primary issue and classifies the request.
3. Employee searches relevant customer records and policies.
4. Employee checks whether the request contains sufficient information.
5. Employee routes the request to the appropriate team and follows up.
   This describes your proposed baseline; we have not yet confirmed the actual workflow, tools, or approval rules used by a real organization.
